# VK Multi Audio Upload

Расширение для Chromium-браузеров (Chrome, Edge, Brave, Opera и т. п.): загрузка MP3 пачкой, авто-плейлисты, скачивание треков и плейлистов, поиск дублей и недоступных записей, а также замена треков копиями из вашего сообщества. Работает на `vk.com` и `vk.ru`, Manifest V3.

> Сделано для ведения музыкального сообщества: многие функции рассчитаны на работу со страницей аудио сообщества (`vk.com/audios-…`).

## Возможности

**Загрузка**
- Перетаскивание MP3 в окно: файлы передаются в штатный диалог загрузки VK.
- Чистка тегов ID3: мусорные метки и водяные знаки в исполнителе и названии, заполнение пустых тегов из имени файла.
- Авто-плейлист после загрузки: новый или существующий (дозагрузка), проверка дубликата по названию, обложка своя или из ID3 первого трека.
- Режим «Проверка»: сверяет имена файлов с треками на странице и ничего не загружает.

**Плейлисты**
- «Плейлист из файлов»: выбираете MP3 на компьютере, расширение находит те же треки среди уже загруженных в сообщество и собирает из них плейлист. Файлы никуда не отправляются.
- «Порядок плейлистов»: сортировка по авторам, перенос в начало и конец, применение порядка из списка ID.
- «Собрать список плейлистов»: текстовый список со ссылками; при сборе треков отмечает недоступные записи и дубли между плейлистами, умеет фильтровать, сортировать и группировать.
- Поиск дубликатов внутри плейлиста и список недоступных треков (с копированием).
- Порядок треков в плейлисте: по порядку выбранных файлов или по треклисту альбома с Genius.
- «Добавить с Genius»: сравнивает треклист альбома с плейлистом, ищет недостающие треки среди загруженных в сообщество и даёт выбрать, какие добавить.
- «Обложка с текстом»: берёт обложку альбома с Genius или ваш файл, накладывает текст (шрифт, цвет, обводка, позиция) и ставит результат обложкой плейлиста.

**Массовые операции**
- Переименование исполнителя и названия у многих треков сразу по файлам или по Genius, с предпросмотром; очистка лишних скобок. Перед открытием панели спрашивает подтверждение, потому что операции затрагивают много записей.

**Скачивание**
- Кнопка «Скачать» у каждого трека.
- Плейлист целиком: одним ZIP-архивом или отдельными файлами, число параллельных потоков настраивается (1–25).
- SoundCloud: загрузка трека или сета по ссылке. На страницах soundcloud.com есть запасной вариант: запись воспроизведения в MP3.

**Звук**
- Эквалайзер: 10-полосный параметрический EQ, компрессор и лимитер (в том числе по истинному пику), измерение громкости LUFS/LRA, пресеты и A/B-сравнение.
- Обфускация аудио при загрузке: набор изменений сигнала и метаданных (спектральный джиттер, дрейф ресемплинга, DC-смещение, микропитч, длительность в теге, перекодирование MP3, метка сообщества). Включается и настраивается в «Настройках».

**Интерфейс**
- Закрепление сайдбара и панели вкладок, смещение контента по горизонтали, скрытие кнопки «Наверх» и блока «Музыка друзей».
- Оптимизация длинных плейлистов: строки вне экрана не отрисовываются.
- Светлая и тёмная темы следуют теме VK.

## Установка

Расширение не опубликовано в магазине, ставится из папки проекта:

1. Скачайте или клонируйте проект.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку проекта.
4. Обновите вкладку с VK.

После обновления кода: «Обновить» на карточке расширения и перезагрузка вкладки VK.

## Где что находится

На странице «Аудиозаписи» рядом с кнопкой «Загрузить аудиозапись» появляются кнопки расширения:

| Кнопка | Что открывает |
|---|---|
| Шестерёнка | Настройки |
| Значок SoundCloud | Скачивание с SoundCloud |
| Значок плейлиста со знаком «+» | Плейлист из файлов |
| Стрелки вверх-вниз со списком | Порядок плейлистов |
| Три полоски | Массовые операции |
| «Собрать список плейлистов» | кнопка над списком плейлистов |

Остальное встроено в сам интерфейс VK: «Скачать» у треков и плейлистов, «Эквалайзер» рядом с плеером, «Проверить на дубликаты» и порядок треков в окне редактирования плейлиста.

## Подмена треков

Если у трека в плеере есть копия в вашем сообществе (совпадают исполнитель и название), плеер играет эту копию. Очередь, шафл и кнопки «вперёд/назад» остаются родными для VK. Подходит, когда оригинал недоступен или ограничен правообладателем, а у сообщества есть полная версия.

- **Источник** — ID сообщества в настройках («Текущая страница» подставляет его со страницы). Замены берутся только из сообщества.
- **Индекс** копий строится и обновляется автоматически: при первом запуске, раз в несколько часов, при смене источника и когда для трека не нашлось пары. Кнопка «Обновить сейчас» запускает обновление вручную.
- **Исключения** — ID плейлистов (например, цензурных версий), треки из которых не предлагаются как замена.
- Во время подмены поверх родной панели плеера показывается её копия: те же кнопки, перемотка, громкость и таймер, плюс переключатель «оригинал / версия сообщества». Подряд идущие подмены переключаются без мигания. Пауза, «играть» и медиаклавиши управляют подменённым звуком; в медиа-блоке браузера показывается название копии.
- За VPN токен VK API может не подходить по IP — тогда расширение использует веб-сессию.

Функция в бете: в редких случаях подмена может не сработать или подхватить не тот трек.

## Настройки

Окно настроек разделено на секции со строкой поиска; изменения сохраняются сразу.

| Секция | Что внутри |
|---|---|
| Загрузка | режим «Загрузка / Проверка», авто-плейлист, обложка, метаданные |
| Подмена треков | включение, сообщество-источник, индекс, исключения |
| Интерфейс | закрепление панелей, смещение контента, скрытие блоков, оптимизация |
| Скачивание | число потоков |
| Обфускация | приёмы обработки аудио и параметры выходного MP3 |

## Разрешения и данные

- `storage` и `scripting`; `downloads` — для сохранения файлов.
- Доступ к `soundcloud.com`, `sndcdn.com`, `snd.sc` (скачивание с SoundCloud) и `genius.com` (треклисты и обложки).
- Настройки и индекс подмены хранятся локально в браузере (`localStorage`). Расширение не имеет собственного сервера и ничего не отправляет разработчику.

## Структура проекта

| Файл | Назначение |
|---|---|
| `manifest.json` | описание расширения (Manifest V3) |
| `content.js` | интерфейс, настройки, загрузка, плейлисты, скачивание |
| `injected.js` | скрипт в контексте страницы: плеер VK, подмена, обращения к внутренностям VK |
| `injector_early.js` | ранний перехват drag-and-drop и подключение `injected.js` |
| `background.js` | сервис-воркер: сохранение файлов, SoundCloud, Genius |
| `style.css` | стили интерфейса расширения |
| `limiter-worklet.js` | аудио-обработка лимитера |
| `lame.min.js` | кодирование MP3 |
| `sc_recorder.js`, `offscreen.*` | запись воспроизведения SoundCloud |
| `tools/emulator_bridge.py` | необязательный помощник для расстановки плейлиста на произвольную позицию через приложение VK в Android-эмуляторе |

## Разработка

Сборки нет: правьте файлы и перезагружайте расширение.

- `injected.js` подгружается заново при обновлении вкладки VK, перезагрузка расширения не нужна.
- `content.js`, `style.css` и `manifest.json` применяются после перезагрузки расширения.

## Ограничения

- Расширение работает с вёрсткой VK, которая со временем меняется: часть функций может ломаться после обновлений сайта.
- Для автоматизации намеренно используется интерфейс страницы, а не только API VK: API бывает нестабилен и привязан к IP.
- Подмена и работа с сообществом рассчитаны на аккаунт с доступом к сообществу-источнику.
